Results / Models and execution harnesses

Better images, weaker physical explanations

Visual accuracy, physical quality, completion budget and tool-use behavior do not move together.

Reported benchmark aggregates

The author-reported results include the following model–harness configurations:

Agent / harnessVisualPhysicalOverall
GPT-6-Astra · Codex0.6930.6330.663
GPT-5.6-Sol · Codex0.6110.5290.570

These are the paper’s scores on its own protocol and task distribution, not absolute measurements of general physical intelligence. Across all nine compared configurations, object scores exceed event scores, and the highest reported motion metric is 0.324.

Verification cadence can change outcomes

In a matched DeepSeek-V4.1-Flash high-effort comparison, the authors report 0.479 overall with Codex versus 0.450 with Claude Code. The traces suggest that final-revision execution, tool-launch allocation and feedback use contribute to the difference. The task budget is three hours and 20 Blender launches.

At low effort, DeepSeek’s aggregate is 0.476 when missing submissions count as zero. Max effort produces higher average quality among completed artifacts, but fewer complete under the budget. This is a completion-versus-quality tradeoff, not proof that more reasoning always helps.

Experimental implication

Agent performance should be measured as a closed-loop system: model + tool environment + test strategy + time budget + quality of physical evidence. A good-looking final frame is only one observable.
