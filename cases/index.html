One hundred and fifty-six reference experiments

The authors’ case manifest records 95 rigid-body, 40 liquid, 12 cloth, and 9 wind cases. Forty-three include explicit counterfactual checks. All are standardized 8-second 4K video references (240 frames, 30 fps). The manifest totals approximately 1.52 GB of reference clips.

Source collections: Pexels 122, Physics-IQ 27, BAAI Physics-aware-videos 5, IRIS 2. The split and dataset include generated reconstructions separately; these page entries describe source tasks only.

How to read this inventory

Reference case ≠ reported anomaly. A case becomes a measured software failure only after a particular generated scene has been inspected, challenged and verified. Here, each record preserves the original video description, hash, licensing and rubric links.
