Audits & verification

Two different verification efforts: 32 symbolic audit blocks and 150 numerical comparison sheets.

Audit stream A / CAS

32 blocks in the published symbolic audit

The institute publishes MATLAB and SymPy source for a 32-block symbolic audit, IDs F0000 through F0031. Its published JSON report, timestamped 4 March 2026, records 32 run, 32 passed, none failed, “global consistency: PASS,” and 2.55 seconds elapsed. These are the institute’s reported run values, not a certification by an external mathematical panel.

The audit page explicitly states that the checks do not establish the physical truth of the starting assumptions. It identifies a downloadable ZIP as the authoritative runnable artifact, rather than browser-rendered source snippets.

Audit stream B / comparison sheets

150 domain-specific worksheets

The second collection, described as template revision 5 locked 1 September 2026, comprises 37 mechanics/gravity (M1–M37), 38 electromagnetism (E1–E38), 38 particle mechanics (P1–P38), and 37 thermodynamics (T1–T37). The institute describes File A as problem-and-prediction sheets and File B as measured values, uncertainties and sources. A SymPy snippet is supplied per worksheet.

A sheet that reproduces its own declared arithmetic is useful for regression testing. A comparison to measured values requires additional checks of calibration provenance, pre-registration, rounding, uncertainties, and whether data were used during model fitting. Those functions are analytically distinct and should not be conflated.

Reproducibility ledger

What would a complete independent audit record?

  1. Exact source archive hash and interpreter/library versions.
  2. Executed program outputs, return codes and test assertion semantics.
  3. A mapping from each tested program to its purported mathematical proposition and to the source page where that proposition appears.
  4. Any untested premises, restricted domains, gauges, regularity assumptions, constants or implicit equivalences.
  5. Original numerical observations distinguished from calibration inputs and withheld measurements.

This is a research-method description, not a ruling on the author's proof. Detailed technical objections belong on separate researcher or derivation pages.
