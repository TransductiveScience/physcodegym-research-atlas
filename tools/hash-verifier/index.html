What a match establishes

An exact match establishes that your selected file has the same bytes as the corresponding standardized reference recorded in the authors' locked source manifest. It does not authenticate the physical event, certify source licensing, or verify an AI’s reconstruction.

A mismatch may mean the file is an upstream original with different encoding, a different benchmark case, or a damaged/modified copy. Keep the source, time and content identity separate.
