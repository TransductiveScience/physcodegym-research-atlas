The manifest records individual SHA-256 hashes and video sizes. Its aggregate clip size is <strong>1,517,045,206 bytes</strong>, approximately <strong>1.52 GB</strong> decimal.</p><p>An independently retrieved upstream video may have a different bitstream or edit than the benchmark’s standardized clip. A reproducible scorer must validate the <em>benchmark reference hash</em> before comparing pixels or timing.</p></section> <section><h2>Generated reconstruction release</h2><p>The Hugging Face dataset card also describes <strong>3,065 generated reconstruction videos</strong> with associated submitted Blender programs. This is separate from the original 156 4K reference clips.</p><p>Access to a generated program still does not certify physical validity.
