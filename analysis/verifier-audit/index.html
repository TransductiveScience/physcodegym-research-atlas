<section><h2>Three epistemic layers</h2><ol><li><strong>Measured state:</strong> coordinates, mesh intersections, energy traces, frame timings and collision distances directly obtained from the submitted program.</li><li><strong>Interpretive criterion:</strong> task-specific physical rubrics say which numerical values are admissible, with what tolerances or controls.</li><li><strong>Verdict:</strong> a tool-assisted verification agent evaluates criteria, combines rubric outcomes and produces a physical-validity score.</li></ol><p>The numerical witness and the score are not interchangeable. A measured overlap is reproducible only with the same geometry and units; whether it violates the intended criterion depends on the benchmark's actual task contract.</p></section> <section><h2>Implemented evidence gates</h2><p>The repository documents disposable preparation of an unchanged submitted scene across 240 frames, preservation of program and input identities, and a finite-state numerical-admission gate. Source flags, script exit status or unsupported claims do not automatically earn a positive score. For the 43 counterfactual cases, ordinary and intervention criteria each receive 50 points before failure caps are applied.</p><p>Unknown or technically unavailable checks are represented as score intervals or explicit gaps, rather than being silently turned into passes.</p></section> <section><h2>Where the uncertainty remains</h2><p>Physical-validity verdicts depend in part on an LLM-based verification agent and authored semantic rubrics. The paper describes manual defect injection but does not provide a comprehensive blinded accuracy evaluation of the verifier. An <a href="https://pith.science/paper/2610.17288">AI-generated Pith review</a> independently <em>argues</em> this is a load-bearing limitation; that review is not itself a controlled reproduction.</p></section> <section><h2>An audit that could settle the concern</h2><ol><li>Create a held-out corpus of validated scenes, deliberately injected failures and ambiguous boundary cases.</li><li>Pre-register what counts as a true positive, false positive and indeterminate verdict.</li><li>Estimate precision, recall and calibration for each failure family, not only a single aggregate.</li><li>Run independent deterministic cross-checks for energy, geometry and collision witnesses.</li><li>Measure inter-run and inter-model judge variability on identical frozen bundles.</li><li>Publish source hashes and minimal witness scenes so that third parties can check them without the original model provider.</li></ol></section><section><h2>A useful stronger claim</h2><p>PhysCodeGym offers an unusually inspectable way to <em>challenge</em> physics-generating agents. Its numerical witnesses merit investigation. A verifier with a published error model would turn that into more robust quantitative evidence about how frequently agents produce invalid mechanisms.</p></section>
